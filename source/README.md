# Minaraverse — source

The live site (https://minaraverse.github.io) is built from this folder.

- `src/` — JavaScript modules and `style.css` (content: data*.js, translations: tr*.js, views: home, tapes, voyage, wild, travel, views2, mystery, v2, v3)
- `build.py` — joins everything into one page. Run `python3 build.py`, then copy `dist/*` to the repository root.
- `NEXT.md` — notes and rules (never spend Higgsfield credits without showing the cost first; draw missing images in code).
- Images live in `/img` at the repository root.
